# SnapCraft

**캡처하고, 모으고, 한 장으로 정리하는 Windows 캡처·편집 도구**

SnapCraft는 화면을 캡처해 차곡차곡 쌓아 두고, 여러 장을 하나의 캔버스에 배치해 주석까지 달아 완성된 이미지로 내보내는 프로그램입니다. 평소에는 트레이에서 가볍게 대기하다가 단축키 한 번으로 캡처하고, 필요할 때만 편집기를 엽니다.

## 다운로드

[**Releases**](../../releases)에서 최신 `SnapCraft-Setup-x.y.z.exe`를 받아 실행하세요.

- Windows 10/11 x64
- 관리자 권한 없이 설치됩니다 (`%LOCALAPPDATA%\Programs\SnapCraft`)
- 별도의 .NET 런타임 설치가 필요 없습니다
- 새 버전 설치 파일을 그대로 실행하면 기존 설정과 세션을 유지한 채 업데이트됩니다

## 주요 기능

### 캡처
| 단축키 | 동작 |
|---|---|
| `Ctrl+Shift+1` | 영역 캡처 |
| `Ctrl+Shift+2` | 창 캡처 |
| `Ctrl+Shift+3` | 전체 화면 캡처 |
| `Ctrl+Shift+4` | 상세(정밀) 캡처 |
| `Ctrl+Shift+5` | 스크롤 캡처 |
| `Ctrl+Shift+V` | 캡처한 이미지를 파일로 빠르게 붙여넣기 |
| `Alt+S` | 캡처 이미지 빠른 저장 |

단축키는 설정에서 바꿀 수 있고, Win+Shift+S 등 다른 방법으로 복사한 이미지도 자동으로 쌓입니다.

### 빠른 붙여넣기
`Ctrl+Shift+V` 로 채팅창, 메일, 탐색기 등 어디에나 캡처를 이미지 파일로 붙여넣습니다. 설정에서 방식을 고를 수 있습니다.
- 선택창을 띄워 여러 장을 골라 한 번에 붙여넣기
- 가장 최근 캡처 1장만 바로 붙여넣기
- 세션의 전체 캡처를 붙여넣기

### 캔버스 편집기
- 여러 개의 캔버스(탭)에 캡처를 원본 크기 그대로 배치하고, 이동·크기 조절·자르기·회전
- 화면 비율과 분할 레이아웃, 자석처럼 붙는 정렬 가이드
- 주석 도구: 번호, 사각형, 둥근 박스, 화살표, 텍스트, 모자이크, 블러, 스포트라이트, 돋보기 인셋
- 색상 자유 선택, 무제한 되돌리기/다시 실행
- 워터마크 등록 후 캔버스 위에서 드래그로 이동, 모서리로 크기 조절
- PNG / JPG / WebP 저장 및 클립보드 복사, 해상도 선택

### 가볍게 상주
편집기를 닫으면 메모리 사용량이 매우 작은 트레이 감시 프로그램으로 전환되어 단축키만 기다립니다. Windows 시작 시 자동 실행도 지원합니다.
