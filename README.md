# SnapCraft

화면을 캡처하고, 여러 장을 캔버스에 배치해 주석을 달고, 한 번에 내보내는 Windows 캡처·편집 도구입니다.

## 다운로드

[**Releases**](../../releases/latest)에서 `SnapCraft-Setup-1.0.0.exe`를 받아 실행하세요.

- Windows 10 / 11 (64비트)
- 별도로 .NET을 설치할 필요가 없습니다(설치 파일에 포함).
- 관리자 권한 없이 내 계정의 `%LOCALAPPDATA%\Programs\SnapCraft`에 설치됩니다.
- 설치 파일에 코드 서명이 없어서 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. `추가 정보` → `실행`을 누르면 진행됩니다.
- 제거는 Windows `설정 → 앱`에서 합니다. 작업 내용(`%LOCALAPPDATA%\SnapCraft`)은 제거해도 남습니다.

## 주요 기능

| 캡처 | 기본 단축키 |
|---|---|
| 영역 캡처 | `Ctrl+Shift+1` |
| 창 캡처 | `Ctrl+Shift+2` |
| 윈도우(모니터 전체) 캡처 | `Ctrl+Shift+3` |
| 상세 캡처(크기를 지정하는 프레임) | `Ctrl+Shift+4` |
| 스크롤 캡처 | `Ctrl+Shift+5` |

단축키는 설정에서 바꿀 수 있습니다.

- **여러 캔버스:** 캔버스를 탭으로 추가하고 전체를 한 번에 내보냅니다(기본 1920×1080).
- **자유 배치:** 이미지를 원본 크기로 놓고 자르기·크기·회전, 캔버스 테두리와 분할선 자석(빨간 가이드), 캔버스 밖은 내보낼 때 잘립니다.
- **주석:** 스텝 번호, 텍스트, 도형, 화살표, 모자이크·블러·스포트라이트, 돋보기(원형/사각, 100~300%). 모든 주석은 이동·크기·회전이 되고 손 모양 포인터로 잡을 수 있습니다.
- **되돌리기:** `Ctrl+Z` / `Ctrl+Y`로 이동·크기·옵션 변경까지 되돌리고 다시 실행합니다.
- **워터마크:** 설정에 등록한 이미지를 캔버스마다 무작위 위치에 넣습니다.
- **히스토리:** 캡처 삭제와 순서 변경, 순서대로 저장·붙여넣기.

사용법은 설치 폴더의 `docs\USER_GUIDE.md`에 있습니다.
